# Workspace Customization Rules

## SCOPE RESTRICTION — HR ADMIN PANEL ONLY

This redesign applies ONLY to the HR Admin Panel / HR Admin dashboard and its HR Admin routes/pages.

Do NOT modify the UI, UX, functionality, routes, components, styling, workflows, or behavior of:
* Candidate/Student panel
* Interviewer panel
* Recruiter panel
* User-facing application
* Candidate portal
* Any other role-based dashboard

If components are shared between HR Admin and other panels, do not make global changes that could affect those panels. Instead, create HR Admin-specific variants, wrappers, styles, or components where necessary.

Preserve all existing functionality outside the HR Admin scope exactly as it is.
